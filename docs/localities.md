# Référentiel de localités du Mali
Source de cadrage : INSTAT, RGPH5, découpage issu de la loi 2023-007 du 13 mars 2023 ; liste de cercles consultée sur https://fr.wikipedia.org/wiki/Cercles_du_Mali. Le catalogue initial inclut le district, les 19 régions représentées par leurs chefs-lieux usuels, une sélection de cercles et localités. Il n'est pas un registre administratif exhaustif ni une garantie de desserte.
148 entrées initiales dans fleet.0015_locality_catalog. Les noms sont utilisés comme destinations exactes dans les trajets existants ; aucun trajet n'est créé. Les noms du catalogue initial sont reproduits dans frontend/src/localities.ts pour les suggestions instantanées hors requête réseau. Toute évolution doit ajouter une migration de données et synchroniser le fichier. La validation serveur s'appuie sur PostgreSQL.

## Géographie (0016)
Les noms existants sont conservés. Métadonnées pays et région, synchronisées avec localities.ts. Les rattachements de cercles sont basés sur le découpage 2023 (INSTAT RGPH5 et https://fr.wikipedia.org/wiki/Cercles_du_Mali). Les localités dont le rattachement précis n'est pas établi dans ces sources gardent une légende générique. Le libellé historique Gargando reste conservé sans rattachement confirmé. Quatre entrées internationales initiales : Kaya (https://gouvernement.gov.bf/actualites/la-region-de-kuilse-est-subdivisee-en-03-provinces/), Kayar (https://www.vie-publique.sn/collectivites-territoriales/regions/thies), Dakar (https://www.vie-publique.sn/collectivites-territoriales/regions/dakar), Abidjan (https://fiscalitelocale.dgi.gouv.ci/districts.php). Catalogue partiel, pas de desserte fictive ni d'autorisation d'exploitation transfrontalière. Ne pas ajouter de noms homonymes sans refonte des identifiants de trajet. Les quatre pays utilisent UTC et XOF ; autres pays à qualifier séparément.
## Aller-retour
GET round-offers compare les départs publiés pour les deux dates et le groupe, recommande une paire au tarif minimum par compagnie, triée par total. Limite 2000 départs par sens, au-delà utiliser la recherche séparée. Une paire n'est pas une réservation : quote puis transaction reserve vérifient la disponibilité. Choix séparés et compagnies différentes restent possibles.
