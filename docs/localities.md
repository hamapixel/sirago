# Référentiel de localités du Mali
Source de cadrage : INSTAT, RGPH5, découpage issu de la loi 2023-007 du 13 mars 2023 ; liste de cercles consultée sur https://fr.wikipedia.org/wiki/Cercles_du_Mali. Le catalogue initial inclut le district, les 19 régions représentées par leurs chefs-lieux usuels, une sélection de cercles et localités. Il n'est pas un registre administratif exhaustif ni une garantie de desserte.
148 entrées initiales dans fleet.0015_locality_catalog. Les noms sont utilisés comme destinations exactes dans les trajets existants ; aucun trajet n'est créé. Les noms du catalogue initial sont reproduits dans frontend/src/localities.ts pour les suggestions instantanées hors requête réseau. Toute évolution doit ajouter une migration de données et synchroniser le fichier. La validation serveur s'appuie sur PostgreSQL.
