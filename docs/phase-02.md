# Phase 02 — Authentification
Inscription en trois étapes après choix du rôle, connexion téléphone/email, sessions Django, CSRF, validation compagnie depuis /admin/. Aucun rôle administrateur ne peut être choisi à l'inscription. Le téléphone est validé syntaxiquement, pas par OTP. Les comptes de développement ne doivent contenir aucune donnée réelle. La récupération du mot de passe, les conditions commerciales définitives, le logo compagnie, les permissions employés et un limiteur partagé de production restent à finaliser avant ouverture publique. Les trajets, ventes et paiements ne sont pas encore actifs. Les compagnies ne peuvent consulter que leur propre fiche.
Test local : docker compose exec backend python manage.py migrate ; docker compose restart backend ; docker compose exec backend python manage.py test ; docker compose exec frontend npm test ; docker compose exec frontend npm run build. Créer un superuser via manage.py createsuperuser et utiliser /admin/ pour valider une compagnie.
