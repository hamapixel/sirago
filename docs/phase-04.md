# Phase 04 — Recherche réelle des voyages
Recherche publique sans authentification, filtrée par trajets publiés futurs, compagnie validée, car et trajet actifs, capacité proposée suffisante. L'API ne renvoie pas de données privées de propriétaire ni d'immatriculation. Le formulaire déclenche une prévisualisation après 250 ms, annule les requêtes obsolètes et propose une page de comparaison avec filtres côté serveur et pagination de 20 résultats. Aller-retour : choix de l'aller puis recherche du trajet inverse, départ retour au plus tôt à l'arrivée de l'aller (aucune durée de correspondance garantie). La sélection affiche un total indicatif sans bloquer de place. Les places proposées ne sont pas des places restantes ; les réservations, blocages, paiements et revalidations transactionnelles seront en phase 05 et suivantes. Les carrousels de trajets et compagnies utilisent des données réelles, limitées à 12 trajets et 30 compagnies. Aucun changement de schéma.
Tests locaux : docker compose restart backend frontend ; docker compose exec backend python manage.py test ; docker compose exec backend python manage.py makemigrations --check --dry-run ; docker compose exec frontend npm test ; docker compose exec frontend npm run build. Tester avec une date future ayant un départ publié, puis suspendre et réactualiser. Tester une recherche sans résultat et le retour avant l'arrivée.
